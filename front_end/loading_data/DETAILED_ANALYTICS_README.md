# Инструкция по использованию функции "Подробная аналитика"

## Описание

Функция `createDetailedAnalytics()` создает новый лист "Подробная аналитика" на основе данных из листов "РНП АБЦ" и "База РНП".

## Как использовать

1. Откройте Google Таблицу с листами "РНП АБЦ" и "База РНП"
2. Откройте редактор скриптов: `Расширения` → `Apps Script`
3. Вставьте код из файла `detailed_analytics.gs`
4. Сохраните проект
5. Запустите функцию `createDetailedAnalytics()`:
   - Выберите функцию в выпадающем списке
   - Нажмите кнопку "Выполнить" (▶️)

## Входные данные (лист "РНП АБЦ")

- **A3:A** (до первой пустой ячейки) - имена (артикулы, предметы, склейки, магазины)
- **C1, D1** - даты начала и конца периода (формат: DD.MM.YYYY или Date)
- **B2:2** (до первой пустой ячейки) - заголовки атрибутов (Заказы, Сумма заказов, Расход на рекламу и т.д.)

## Структура результата

Создается новый лист "Подробная аналитика" (или "Подробная аналитика (2)", "Подробная аналитика (3)" и т.д., если лист уже существует):

- **C1, D1, E1...** - даты периода (все даты между C1 и D1 включительно)
- **Столбец A** - объединенные ячейки с названиями атрибутов
- **Столбец B** - имена, повторяющиеся для каждого атрибута
- **Столбцы C, D, E...** - значения из листа "База РНП" для каждой комбинации (имя × дата × атрибут)

## Источник данных

Данные берутся из листа **"База РНП"**:
- Поиск осуществляется по комбинации: **Дата** (столбец A) + **Имя** (столбец C)
- Значения берутся из столбцов, соответствующих заголовкам атрибутов

## Форматирование

- Заголовки дат: жирный шрифт, голубой фон
- Столбец A (атрибуты): жирный шрифт, серый фон
- Столбец B (имена): желтый фон
- Автоматическая подгонка ширины столбцов

## Обработка ошибок

- Если данных нет для какой-то комбинации (имя × дата × атрибут), ячейка остается пустой
- Если атрибут из "РНП АБЦ" не найден в заголовках "База РНП", он пропускается (с предупреждением в консоли)
- При отсутствии необходимых листов или данных функция выдает ошибку с описанием проблемы
