## 🔧 Конфигурация

### Изменение периода (DAYS_BACK)

Отредактируйте `header_config.py`:

```python
# Было:
DAYS_BACK = 90  # последние 90 дней

# Хотим 180 дней:
DAYS_BACK = 180
```

Перезапустите функцию.

---

### Добавление нового хедера

В `header_config.py` добавьте новую колонку:

```python
HEADER_MAPPING = {
    # ... существующие ...
    
    "S": {  # Новая колонка
        "name": "Мой новый метрик",
        "source": "open_card_count",  # откуда брать
        "from_table": "cr_daily_stats",
        "type": "metric",
        "aggregation": "SUM",  # для уровней 2, 3, 4
    },
}
```

Google Sheets автоматически подхватит новый хедер.

---

### Изменение названия листа

В `header_config.py`:

```python
# Было:
SHEET_NAME = "База РНП"

# Хотим:
SHEET_NAME = "My Custom Sheet Name"
```

Лист будет создан автоматически.

## 🔍 Фильтрация в Google Sheets

После обновления используйте встроенные фильтры Google Sheets:

### Видеть только артикули

1. Кликните на хедер
2. Data → Create a filter
3. Признак → Filter by condition
4. "Артикул"

### Видеть только предметы

1. Признак → Filter by condition
2. "Предмет"

### Видеть только склейки

1. Признак → Filter by condition
2. "Склейка"

### Видеть только магазин

1. Признак → Filter by condition
2. "Магазин"

## 🐛 Troubleshooting

### Ошибка: "HEADER_MAPPING пуст"

**Проверьте:**
- `header_config.py` существует
- `HEADER_MAPPING` не пуст
- Python может прочитать файл

### Ошибка: "Хедеры Google не совпадают"

**Решение:**
- Удалите текущие хедеры вручную
- Функция запишет правильные хедеры
- ИЛИ обновите хедеры в Google вручную

### Ошибка подключения к БД

**Проверьте:**
- `SUPABASE_DB_URL_LOCAL` в `api_keys.py`
- БД доступна
- Таблицы существуют: `adv_params`, `cr_daily_stats`, `products`

### Ошибка подключения к Google

**Проверьте:**
- `GOOGLE_CREDENTIALS_INFO` в `api_keys.py`
- `RNP_REPORT_ID` в `api_keys.py`
- Сервис аккаунт имеет доступ к таблице

## 📈 Оптимизация

### Увеличение скорости

Если обновление медленное:

1. **Уменьшьте период:**
   ```python
   DAYS_BACK = 30  # вместо 90
   ```

2. **Используйте локальную БД:**
   Убедитесь, что `SUPABASE_DB_URL_LOCAL` указывает на локальное подключение

### Уменьшение размера данных

Если Google Sheet становится слишком большим:

1. **Архивируйте старый лист:**
   - Сохраните "base_rnp" отдельно
   - Создайте новый "Base RNP 2025"

2. **Разделите данные:**
   - Создайте отдельные листы для разных уровней

## 🔗 Связь с другими функциями

RNP BASE работает **перед** другими РНП функциями:

```
RNP BASE ✅
   ↓
RNP по артикулам (читает из "База РНП")
RNP по склейкам
RNP по предметам
RNP по магазину
```

Это обеспечивает:
- Единый источник данных
- Консистентность данных
- Backup перед обновлением
