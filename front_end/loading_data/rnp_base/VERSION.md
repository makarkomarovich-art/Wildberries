# RNP BASE - Version History

## v1.0 (2025-01-15)

### 🎉 Начальный релиз

#### Функции:
- ✅ 4 независимых уровня агрегации
  - LEVEL 1: vendor_code (Артикулы) - БЕЗ GROUP BY
  - LEVEL 2: category_wb (Предметы) - GROUP BY category_wb, date
  - LEVEL 3: imt_id (Склейки) - GROUP BY imt_id, date
  - LEVEL 4: Магазин - GROUP BY date

- ✅ Один лист "База РНП" для всех 4 уровней
- ✅ Фильтрация по признаку в Google Sheets
- ✅ Автоматический backup в "backup_rnp"
- ✅ 18 хедеров (Дата, Признак, Имя, Заказы, Сумма заказов, Расход на рекламу, ДРР, ...)
- ✅ Динамическое маппирование хедеров
- ✅ Данные за последние 90 дней (конфигурируется)
- ✅ Валидация конфигурации и Google Sheets хедеров
- ✅ Детальное логирование
- ✅ Интеграция в оркестратор РНП

#### Технические детали:
- **Язык:** Python 3.7+
- **Зависимости:**
  - `psycopg2` - подключение к PostgreSQL (Supabase)
  - `google-api-python-client` - Google Sheets API
  - `google-auth-httplib2` - Google Auth
- **БД:** Supabase PostgreSQL
  - Таблицы: `adv_params`, `cr_daily_stats`, `products`
- **Google Sheets:** Единая таблица RNP_REPORT_ID
  - Лист 1: "База РНП" (основной)
  - Лист 2: "backup_rnp" (автоматически)

#### Архитектура файлов:
```
frontend/loading_data/rnp_base/
├─ __init__.py
├─ header_config.py              (конфигурация)
├─ structure_validator.py        (валидация)
├─ rnp_base_fetcher.py           (fetch)
├─ rnp_base_aggregator.py        (агрегация)
├─ rnp_base_transformer.py       (трансформация)
├─ rnp_base_writer.py            (запись)
├─ rnp_base_orchestrator.py      (main)
├─ README.md                     (документация)
├─ USAGE_EXAMPLES.md             (примеры)
└─ VERSION.md                    (история)
```

#### Операции:
1. Валидация конфигурации
2. Fetch хедеров из Google
3. Fetch текущих данных (backup)
4. Fetch сырых данных из Supabase (4 уровня)
5. Агрегация данных
6. Объединение уровней
7. Трансформация в Google формат
8. Создание/обновление backup листа
9. Очистка основного листа
10. Запись новых данных
11. Итоговый отчёт

#### Размер данных (примерно):
- LEVEL 1 (Артикулы): ~90 000 строк
- LEVEL 2 (Предметы): ~1 800 строк
- LEVEL 3 (Склейки): ~27 000 строк
- LEVEL 4 (Магазин): 90 строк
- **ИТОГО:** ~118 890 строк

#### Интеграция:
- Запускается **первым** в оркестраторе РНП (до других функций)
- Предоставляет единую базу данных для других РНП функций
- Создает автоматический backup перед любыми обновлениями
