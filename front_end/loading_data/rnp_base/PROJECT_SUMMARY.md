## 🎯 Функциональность

### 4 Независимых уровня агрегации

| Уровень | Ключ | GROUP BY | Размер | Признак | Особенности |
|---------|------|----------|--------|---------|------------|
| **1** | vendor_code | ❌ НЕТ | ~90 000 | Артикул | Без агрегации, полные атрибуты |
| **2** | category_wb | ✅ (cat, date) | ~1 800 | Предмет | SUM/AVG агрегация |
| **3** | imt_id | ✅ (imt, date) | ~27 000 | Склейка | SUM/AVG агрегация |
| **4** | магазин | ✅ (date) | 90 | Магазин | SUM/AVG агрегация |

**ИТОГО: ~118 890 строк в одном листе**

---

### 18 Хедеров (маппированы в A-R)

```
A: Дата                          ← Dimension
B: Признак                       ← Dimension (Артикул/Предмет/Склейка/Магазин)
C: Имя                           ← Dimension (vendor_code/category_wb/imt_id/"Магазин")
D: Заказы                        ← Metric
E: Сумма заказов                 ← Metric
F: Расход на рекламу             ← Metric
G: ДРР                           ← Calculated (E/F)
H: Клики общие                   ← Metric
I: В корзину                     ← Metric
J: Конверсия в корзину           ← Metric (%)
K: Конверсия в заказ             ← Metric (%)
L: CPM                           ← Metric
M: Рекламные просмотры           ← Metric
N: Рекламные клики               ← Metric
O: CTR                           ← Metric (%)
P: CPC                           ← Metric
Q: Остатки WB                    ← Metric (NULL для Level 2, 3, 4)
R: Цена одного заказа            ← Metric
```

## 💡 Особенности

### ✨ Уникальные черты

1. **4 независимых уровня** - каждый обрабатывается отдельно
2. **Один лист** - всё в одном месте, удобнее, чем 4 отдельных листа
3. **Динамические хедеры** - просто отредактируйте header_config.py
4. **Ежедневные данные** - за каждый день, не суммируется
5. **Автоматический backup** - безопасность перед каждым обновлением
6. **Полная валидация** - конфигурация, хедеры, данные
7. **Интеграция в оркестратор** - запускается ПЕРВЫМ
