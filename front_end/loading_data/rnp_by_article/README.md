# РНП по артикулам

## Описание

Модуль для обновления отчета "РНП" (Рентабельность и Производительность) по артикулам в Google Sheets.

## Структура

- `aggregate_data.py` - Функции получения данных из БД
- `update_sheet.py` - Основная функция обновления
- `orchestrator.py` - Оркестратор для запуска

## Запуск

```bash
# Через orchestrator
python -m front_end.loading_data.rnp_by_article.orchestrator

# Или напрямую
python -m front_end.loading_data.rnp_by_article.update_sheet
```

## Ключевые настройки

| Параметр | Значение | Линия |
|----------|----------|-------|
| `ATTRIBUTES_PER_ITEM` | 16 | 51 |
| `FIRST_DATE_COLUMN_INDEX` | 6 (F) | 48 |
| `SHEET_NAME` | "РНП" | (из api_keys) |

## Атрибуты (16 шт)

1. Заказы
2. Сумма заказов
3. Расход на рекламу
4. ДРР
5. Клики общие
6. В корзину
7. Конверсия в корзину
8. Конверсия в заказ
9. CPM
10. Рекламные просмотры
11. Рекламные клики
12. CTR
13. CPC
14. Остатки WB
15. Цена одного заказа
16. Журнал изменений

## Логика

1. Читает структуру листа "РНП"
2. Находит все артикулы в столбце "Артикул"
3. Получает данные из БД (cr_daily_stats + adv_params)
4. Сравнивает с Google Sheets
5. Обновляет отличающиеся значения
6. Валидирует результат
